## 下一步研究输入（Open）

以下问题来源于当前 PRD，作为候选验证方向，不是已确认的市场结论，也不是另一份任务状态表。

| 待验证问题 | 现有依据与缺口 | 可选的下一份证据 |
| --- | --- | --- |
| 目标用户是否愿意随身携带并反复使用双拇指乐器？ | PRD 第 2 节有定位和初步测试陈述；持续使用、舒适度与重复使用证据待补。 | 围绕真实使用场景的短访谈与可复现演奏观察，记录样本和条件。 |
| EP-1 / EO-1 的完整体验是否形成可辨识价值？ | PRD 第 7 节是产品目标，已有竞品资料不能代替用户体验证据。 | 对具体声音和交互原型的对照体验，区分个人偏好与普遍结论。 |
| 成本、售价、首批规模与备件承诺能否匹配？ | PRD 第 14 节记录约USD229初步目标，商业规格仍待决，竞品售价不直接决定自身定价。 | 针对选定工程的成本资料与明确样本的购买意向反馈；不反推销量。 |
| 用什么内容与渠道能让用户理解演奏价值？ | 已有宣发覆盖与社区来源可供筛选，尚未指定本项目推广渠道或预算。 | 小范围演示反馈；实际发布计划确定后再记录目标、内容、渠道和观察结果。 |

选中某个问题后，在 BACKLOG 记一项动作；验证目标、方法和观察放 EXPERIMENTS 或已有研究记录。只有证据支持且做出决定后，才更新 PRD 中相关定义或商业边界，必要时在 DECISIONS 保存理由。

目前不建立营销日历、客户数据库、渠道评分或商业预测模板。出现实际活动、重复研究或协作交接需求后再拆页；一次性线索仍可直接留在 BACKLOG。
