# PISCIS-I 电钢琴项目

本仓库保存项目市场调查资料和 MDA 电钢琴 / F101 实时演奏原型。

## 目录

- `市场调查资料/`：已有的竞品、市场与社区研究材料。
- `firmware/MDA_F101实时演奏版/`：F101 板端合成程序、Windows 中文 37 键界面、编译与 RAM 加载脚本。

## 当前原型

电脑界面发送按键状态，YuzukiNeko F101 开发板运行 MDA 电钢琴音源，经 USB 回传音频，由 Windows 默认播放设备输出。支持 37 键界面、低中高音区切换、延音和最多 32 复音。

当前实际硬件只有 F101 开发板，尚未连接 ES8388、屏幕或实体 MIDI 键盘。程序仅临时加载到 PSRAM；断电后需要重新加载，尚未烧写 Flash。

## 已验证状态（2026-10-25 整理）

- 用户实际演奏确认正常。
- 此前 10 秒硬件测试通过：1004 次响应、1003 块音频、播放缓冲断流 0 次。
- 最慢板端音频块计算耗时 2322 微秒，每块音频播放时长 10000 微秒。
- 记录的 RAM 预留量为 1,065,632 字节，板上 RAM 总量为 16 MiB。
- 长时间稳定性、端到端延迟、实体 MIDI 键盘、ES8388/I2S 输出和屏幕功能仍待验证。

具体使用方法见 [实时版说明](firmware/MDA_F101实时演奏版/说明.md)，测试数据见 [验证状态](firmware/MDA_F101实时演奏版/验证状态.json)。本次上传未重新执行硬件测试。

## 开发环境与使用前提

当前源码快照来自本地已验证提交 `5e14450`。原本地工程和生成文件继续保留。

脚本沿用作者电脑上已验证的环境路径，尚不是下载后即可在任意电脑直接运行的安装包：

- Windows 11；Windows C++ 编译器默认路径为 `F:\c\ucrt64\bin\g++.exe`，可通过 `build-pc.ps1 -Compiler` 指定。
- WSL 发行版为 `MIDI-F101-Ubuntu`，SDK 工作区为 `/home/midi/f101-zephyr`。
- Zephyr SDK 使用 YuzukiHD/zephyr 的 `zephyr-v4.2.2-f101`，固定上游 revision 为 `84146a9e508c4e92135100413bc64563f9f7a6c3`。
- 工具链为 Xuantie V3.2.0-20250627 / GCC 14.1.1。
- `build.cmd` 和 `build.sh` 引用本地 `D:\MIDI工具箱\F101开发环境\MDA_F101实时演奏版`。
- RAM 加载脚本需要开发环境目录中的 `工具/xfel-windows-v1.4.0/xfel.exe`。

在其他电脑使用时，需要先准备相应 SDK、工具链及路径。EXE、BIN、SDK、工具链和原板固件备份未包含在此次源码上传中；`output/` 为被 Git 忽略的生成目录。
