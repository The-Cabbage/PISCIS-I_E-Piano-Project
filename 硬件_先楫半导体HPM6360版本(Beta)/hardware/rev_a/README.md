# PISCIS-I HPM6360 Rev.A engineering project

This directory is the reconstructed Rev.A design generated by `tools/generate_reva_hardware.mjs`. The hierarchical schematics intentionally remain in KiCad legacy `.sch` syntax so they can be generated and inspected as text; see `VALIDATION.md` for the KiCad 10 conversion status.

Design basis: official HPM SDK `boards/hpm6300evk/pinmux.c` for FEMC and SDXC0, and `soc/HPM6300/HPM6360/hpm_iomux.h` for XPI0/I2S/SPI assignments.

The folder also contains `PISCIS-I_Control_8x8.sch`, the matching daughterboard with MCP3208, two 74HC165 devices, eight filtered potentiometer inputs and eight A/B encoder headers. Both PCB files contain every BOM footprint and an unrouted functional placement baseline.

Before fabrication: verify the PAM8302A order-code pinout, the SM8082 feedback ratio, HPM6360 exposed-pad dimensions, microSD switch polarity, and every imported EasyEDA footprint against the purchased lot.
