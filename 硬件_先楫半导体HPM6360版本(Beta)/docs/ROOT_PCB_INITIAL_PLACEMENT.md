# 根目录 PCB 初期排布记录

日期：2026-09-28

## 本轮结果

- 采用当前有效的 70 mm × 70 mm 圆角板框；四角开孔直径约 3 mm。
- 清除了左侧已废弃的旧矩形板框和旧 POGO 注记，避免同时存在两个 Edge.Cuts 轮廓。
- 已排布 78 个现有/可加载封装：主控置中，Flash 与内核电源置于左侧，模拟电源置于右侧，升压与串口电路置于下部，测试点沿下沿排列。
- 将原理图中已有封装文件的 U3（SM8082AAAC）补入 PCB，并匹配其 5 个焊盘网络。
- 将主 USB 口 J1（GCT USB4105）置于上沿，将串口 USB 口 USBC1（TYPE-C-31-M-12 / C165948）置于右沿，并完成焊盘网络映射。
- 将 24 MHz 晶振 X1（X252024MOB4SI / C371129）置于 MCU 晶振引脚侧，并完成四个焊盘网络映射。
- 板上仍为按键、保险丝和晶振等尚未落板的器件保留空间，后续补齐封装后再收敛布局。

## 几何检查

- 78/78 个封装均有 courtyard，可完成检查。
- Courtyard 包围框重叠：0。
- 超出 70 mm × 70 mm 板框：0。
- J1 的 courtyard 在上侧板边有预期机械外伸：1。
- 进入四个安装孔 4.0 mm 半径保留区：0。

检查命令：

```sh
node tools/check_root_pcb_placement.mjs
```

## 尚未落板的原理图器件

- `F1`：原理图的 Footprint 字段为空。
- `SW1`、`SW2`：原理图已填写私有库封装名，但当前私有 `.pretty` 库中没有对应 `.kicad_mod` 文件。

在上述 3 个封装补齐前，本结果只作为初期功能分区和后续布线基线，不作为可投板版本。

KiCad CLI 可以载入、导出坐标并完成 3D 渲染；当前 `pcb drc` 命令在此工程上抛出未处理异常，因此本轮采用独立 courtyard、板框和安装孔净空检查，尚不能视作完整 DRC 通过。
