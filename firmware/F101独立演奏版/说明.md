# F101 独立演奏版

MIDI 键盘接入 F101 的 USB 数据口。F101 作为 USB 主机接收演奏消息，在板上运行 MDA 电钢琴与 Hammond 风琴音源，通过 I²S 把音频送给 ES8388，从 PISCIS 原型主板的 J5 耳机口输出。演奏时只需给主板供电并接上键盘和耳机。

## 这版实现

- 接收全部 16 个 MIDI 通道上的按键、力度、延音和音量消息。音量使用标准 CC7，并为本次实测的 Keystation Mini 32（USB ID `0A4D:129D`）增加 CC79 音量映射。
- 保持浮点混音，在转换为 16 位立体声前做双声道前瞻峰值限制。最大软件增益设为 8 倍，ES8388 模拟增益设为 +3 dB。多音叠加接近峰值上限时会触发限幅。
- 实物为 YuzukiNeko F101 V1.4、PISCIS 原型主板和 M-Audio Keystation Mini 32。原型已确认可以独立演奏。实测范围与应用镜像记录见[验证状态](验证状态.json)。

## 构建

使用包含 YuzukiNeko F101 板级支持和 CherryUSB 的 Zephyr 工作区。在本次板测中，Zephyr 为 4.2.2，CherryUSB 为 1.6.1，Xuantie GCC 为 14.1.1。工作区根目录的 `env.sh` 负责初始化工具链和 west 环境。[YuzukiNeko Zephyr 构建文档](https://yuzukihd.github.io/YuzukiNeko/dev/zephyr/zephyr-build-run/)

在 Linux 或 WSL 中进入本目录，设置实际的工作区路径并运行构建脚本。

```bash
F101_WORKSPACE=~/f101-zephyr bash build.sh
```

脚本用 `west build -b yuzukineko` 构建，并把程序和构建记录放入本目录的 `output/`。板测使用带应用头的镜像，部署到已有引导布局的 Flash 应用区 `0x200000`。仓库记录的是该镜像的校验值，构建脚本只编译固件。
