# F101 实时电钢琴原型

独立于已验证录音版和原 Windows 电钢琴。四个 MDA 核心文件保持原样，来源及 SHA256 见 core-import.json。

使用：build.cmd 编译板端，build-pc.ps1 编译电脑端。按住 FEL 重新插入 USB，运行 load-ram.cmd。待 USB 串口出现后，双击“打开实时电钢琴.cmd”。仅加载 PSRAM，不写 Flash。

电脑界面：连续 37 键，鼠标演奏；AWSEDFTGYHUJK 演奏中间音区，Z/X/C 切换低中高音区，空格延音，Esc 关闭。音频由 F101 计算，电脑默认播放设备输出，目前无需 ES8388。请关闭其他串口工具和录音版接收脚本。

代码：src/main.cpp 每次按键快照生成 441 帧（10 ms），最多 32 复音；src/protocol.h 包含共享协议、序号和 CRC32；src/usb_transport.c 处理 USB；pc/RemoteEngine.h 连接板子；pc/main_pc_mda.cpp 提供中文键盘及 WinMM 四块播放缓冲。电脑端不链接 MDA 合成实现。

当前已完成电脑协议校验和 37 键区域检查。实体板 10 秒实时播放测试已通过，包含 32 复音、松键及界面短暂停顿测试，未检测到播放缓冲断流。40 ms 缓冲配置不等于端到端延迟实测。

板端 100 ms 未收到请求会清除声部。USB 超时或数据校验错误时电脑停止播放并提示重连。短于一次 10 ms 更新周期的按键可能无法采到，后续可升级为带时间戳的 MIDI 事件队列。使用相同 Windows 音色参数（高频 0.20、硬度 0.4）。

原核心保留 GPL-3.0-or-later 声明；USB 描述符保留 CherryUSB Apache-2.0 声明。SDK 和工具链使用已验证的 D 盘开发环境。


板上实测：1004 次响应，1003 块音频，峰值 9054，播放缓冲断流 0 次；最慢板端计算 2322 微秒，每块播放时长 10000 微秒。测试退出码 0。详见 output/hardware-smoke.log 和 验证状态.json。长期稳定性及端到端延迟仍需后续实测。

## 开发环境与使用前提

当前源码快照来自本地已验证提交 `5e14450`。原本地工程和生成文件继续保留。

脚本沿用作者电脑上已验证的环境路径，尚不是下载后即可在任意电脑直接运行的安装包：

- Windows 11；Windows C++ 编译器默认路径为 `F:\c\ucrt64\bin\g++.exe`，可通过 `build-pc.ps1 -Compiler` 指定。
- WSL 发行版为 `MIDI-F101-Ubuntu`，SDK 工作区为 `/home/midi/f101-zephyr`。
- Zephyr SDK 使用 YuzukiHD/zephyr 的 `zephyr-v4.2.2-f101`，固定上游 revision 为 `84146a9e508c4e92135100413bc64563f9f7a6c3`。
- 工具链为 Xuantie V3.2.0-20250627 / GCC 14.1.1。
- `build.cmd` 和 `build.sh` 引用本地 `D:\MIDI工具箱\F101开发环境\MDA_F101实时演奏版`。
- RAM 加载脚本需要开发环境目录中的 `工具/xfel-windows-v1.4.0/xfel.exe`。

在其他电脑使用时，需要先准备相应 SDK、工具链及路径。EXE、BIN、SDK、工具链和原板固件备份未包含在此次源码上传中；`output/` 为被 Git 忽略的生成目录。
